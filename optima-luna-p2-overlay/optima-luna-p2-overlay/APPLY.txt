Overlay for the existing Optima-luna repository.

Copy the new src/*.py files, tests/test_*.py files and docs/VALIDATION.md into the repo.
Replace README.md, AI_USAGE.md and ACKNOWLEDGEMENTS.md with the updated copies.
Append config.validation.append.yaml to the existing config.yaml. Do NOT replace the
existing config.yaml: preserve the P1 shared feature, grid, scoring, paths and weights.

This overlay intentionally does NOT contain src/grid.py, src/config.py, Makefile or
requirements.txt. Keep the existing P1 grid, config loader and pinned dependencies.

Required existing APIs:
- src.config.load_config(), src.config.ROOT
- src.grid.build_grid(), src.grid.grid_spec(), src.grid.lonlat_to_xy()

Then run:
  python -m pytest -q
  python -m src.synth
  python -m src.model
  python -m src.pairing
  python -m src.validate

Parquet output requires pyarrow, already pinned in requirements.txt.
